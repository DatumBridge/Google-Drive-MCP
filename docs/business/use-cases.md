# Use Cases

| Actor | Goal | Tools |
|-------|------|-------|
| AI agent | Draft a brief in Docs | `create_document`, `append_document_text` |
| AI agent | Populate a tracker | `create_spreadsheet`, `update_sheet_range`, `append_sheet_rows` |
| AI agent | Build a short deck | `create_presentation`, `add_slide`, `insert_slide_text` |
| AI agent | Collect survey answers | `create_form`, `add_form_question`, `list_form_responses` |
| AI agent | Store an architecture diagram | `create_diagram`, `update_diagram`, `read_diagram` |
| Operator | File hygiene | Drive tools (`list_files`, `move_file`, `delete_file`) |
