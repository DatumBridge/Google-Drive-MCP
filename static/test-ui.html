Connect with Google (OAuth – Personal Drive)

Sign in with your Google account. Files will appear in your personal Drive. Token is saved to this browser (survives refresh).

If you get redirect_uri_mismatch: add the redirect URI from /oauth/info to Google Cloud Console → Credentials → OAuth client → Authorized redirect URIs.

Credentials: Click "Connect with Google" above, or run python scripts/oauth_connect.py to get an OAuth token. Token is auto-filled in all forms.
